= vello-d

High-performance, GPU-accelerated 2D vector graphics for D, powered by link:https://github.com/linebender/vello[Vello] (Rust).

link:https://dlang-supplemental.github.io/docs/vello-d/index.html[Explore the docs] ·
link:https://github.com/dlang-supplemental/vello-d/issues[Report Bug] ·
link:https://github.com/dlang-supplemental/vello-d/issues[Request Feature]
endif::[]

Install: `dub add vello-d` (after building the Rust bridge below).

== About The Project

=== Key Features

* **GPU Backends**: Native support for **Vulkan** and **DX12** via `wgpu`.
* **Surfaces**: Windows `HWND`, X11 (`Display*` + window id), Wayland (`wl_display*` + `wl_surface*`).
* **Scene API**: fills, strokes, rounded rects, circles, Bézier paths, clip layers, linear/radial gradients, RGBA8 images, TrueType glyph runs, UTF-8 text (`drawText` / `measureText`).
* **Multi-Window Rendering**: Create multiple windows running on different GPU backends within a single process.
* **Threaded Rendering**: Decouple render loops from the Win32 message pump during move/resize.
* **RAII Bindings**: Ergonomic D wrappers for Vello's scene and context management.

== Getting Started

=== 1. Build the Rust Bridge

Vello is a Rust engine, so you first need to build the C-compatible bridge:

[source,powershell]
----
cd vello_bridge
cargo build --release
----

Full walkthrough: link:https://dlang-supplemental.github.io/docs/vello-d/quick-start.html[Quick start].

== Usage

The `demos/` directory contains several configurations:

[cols="1,2,3",options="header"]
|===
| Configuration | Command | Description

| **Simple** | `dub run -c simple` | A basic single-window Vulkan renderer.
| **Multi-Backend** | `dub run -c multi` | **Vulkan + DX12** windows in one process (shared main thread).
| **Threaded** | `dub run -c threaded` | **Vulkan + DX12** on background threads. **Highly recommended on Windows.**
|===

=== Text rendering (0.1.4+)

[source,d]
----
ubyte[] font = /* load .ttf */;
float w = scene.drawText(font, 0, 32.0f, 40.0, 120.0, 255, 255, 255, 255, "Hello!");
----

See link:https://dlang-supplemental.github.io/docs/vello-d/text-rendering.html[Text rendering] for `drawGlyphs`, constraints, and C ABI details.

=== Why Threaded Rendering?

On Windows, standard single-threaded main loops block when a user moves or resizes a window. The `-c threaded` configuration keeps animation smooth during drags.
